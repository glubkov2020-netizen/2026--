Руководство пользователя

1. Быстрый старт

Три способа загрузить данные:

  • Кнопка «Загрузить базу» — если рядом с index.html лежит data.js.
  • Кнопка «Демо» — синтетические данные 10×10.
  • Вручную или CSV/JSON — вставьте в поле, нажмите «Проверить и добавить».

2. Форматы данных

CSV (разделитель ; или ,):

Регион;Год;Значение;Статус;Примечание
Кемеровская обл.;2019;34.5;факт;Отчёт Минэнерго 2019
Москва;2019;68.2;факт;Мосэнерго

JSON:

[{"region":"Кемеровская обл.","year":2019,"value":34.5,"status":"факт","note":"Отчёт"}]

4. Горячие клавиши

  • ~ — терминал
  • Ctrl+K — палитра команд
  • Ctrl+B — свернуть сайдбар
  • Ctrl+Z / Ctrl+Y — undo/redo
  • ↑ / ↓ — история команд
  • Tab — автодополнение
  • Esc — закрыть модалку

Источники данных

Платформа не поставляет данные. Пользователь вводит их сам из официальных источников:

  • Минэнерго России — отчёты, СиПР
  • Росстат — ТЭБ, региональная статистика
  • СО ЕЭС — отчёты ЕЭС
  • АТС — оптовый рынок
  • data.gov.ru — открытые наборы
Важно. Seed-база data.js содержит оценочные значения. Для официальных отчётов — только первичные источники.

Методика расчётов

Описательные статистики

Среднееx̄ = (Σ xᵢ) / n
Медиананечётное n: x₍ₙ₊₁₎/₂; чётное: (x₍ₙ/₂₎+x₍ₙ/₂₊₁₎)/2
σ (выборочное)σ = √[Σ(xᵢ−x̄)²/(n−1)]
CVCV = (σ/x̄)·100%
CAGRCAGR = [(x_кон/x_нач)^(1/n)−1]·100%

Тренды

МНКŷ = a + b·t; b = Σ(tᵢ−t̄)(yᵢ−ȳ)/Σ(tᵢ−t̄)²; a = ȳ−b·t̄
Полином-2ŷ = a₀ + a₁·t + a₂·t² (с центрированием t)
Экспонентаŷ = a·e^(b·t) (МНК к ln y)
R²R² = 1 − SS_res/SS_tot (null при SS_tot=0)
MAPEMAPE = (100/n)·Σ|(yᵢ−ŷᵢ)/yᵢ| (null при >30% нулей)

Аномалии

z-scorez = (x−x̄)/σ; |z|>2 — выброс
IQRQ1, Q3; IQR=Q3−Q1; выброс x<Q1−1.5·IQR или x>Q3+1.5·IQR
MAD (scaled)MAD=median(|xᵢ−median(x)|); scaled=1.4826·MAD; выброс |xᵢ−median|>3·scaled

Структура

HHIHHI = Σ sᵢ², sᵢ — доля в %
ДжиниG = Σᵢ(2i−n−1)·x₍ᵢ₎/(n·Σx)
CR-kCR_k = (Σ топ-k / Σ всех)·100%
ЭнтропияH = −Σpᵢ·ln(pᵢ)

Корреляции

Пирсонr = Σ(xᵢ−x̄)(yᵢ−ȳ)/√[Σ(xᵢ−x̄)²·Σ(yᵢ−ȳ)²]
Манн-КендаллS = Σᵢ Σⱼ₌ᵢ₊₁ sign(xⱼ−xᵢ); Var(S) с поправкой на ties; Z = (S−sign(S))/√Var(S)

Кластеризация

k-means++Инициализация k-means++, 10 запусков, лучший по inertia
PCAСтепенной метод, maxIter=1000, tolerance=1e-10

Политика конфиденциальности

Платформа не собирает персональные данные. Все вычисления в браузере. Данные на сервер не отправляются.

Что хранится в localStorage

  • Введённые данные (для автосохранения)
  • Настройки (единица, точность, тема)
  • Флаг согласия

Управление

  • Принять — автосохранение включено
  • Только необходимые — автосохранение отключено
  • Отозвать — Настройки → «Согласие и cookies»

Cookie

HTTP-cookies не используются. Всё — в localStorage, который подпадает под требования согласия.
